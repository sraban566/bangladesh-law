# ChatGPT-তে ইনস্টল / Install on ChatGPT

## পদ্ধতি ১: Custom GPT (সবচেয়ে ভালো)

1. ChatGPT-তে **Explore GPTs → Create**-এ যান
2. **Configure** ট্যাবে:
   - **Name**: `Bangladesh Law Assistant`
   - **Instructions**: এই repo-র `SKILL.md`-এর কনটেন্ট পেস্ট করুন
   - **Knowledge**: repo-র সব `.md` ফাইল আপলোড করুন (zip নামিয়ে extract করে আপলোড)
3. Save → আপনার ডিজিটাল আইন সহকারী তৈরি
4. চাইলে **Public** করে লিংক শেয়ার করতে পারেন — তাহলে অন্যরাও ব্যবহার করতে পারবে

## পদ্ধতি ২: Custom Instructions (সাধারণ চ্যাটের জন্য)

1. ChatGPT Settings → **Personalization / Custom Instructions**
2. "How would you like ChatGPT to respond?"-এ `AGENTS.md`-এর নিয়মগুলো পেস্ট করুন
3. চ্যাটে প্রয়োজনমতো markdown ফাইল পেস্ট করুন

> ⚠️ ফ্রি প্ল্যানে Knowledge ফাইল সাইজ/সংখ্যা সীমিত থাকতে পারে — তখন `SKILL.md`, `guides/` ও `data/laws-index.json` আগে আপলোড করুন।
