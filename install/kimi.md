# Kimi-তে ইনস্টল / Install on Kimi

## পদ্ধতি ১: Kimi সেশনে সরাসরি

1. Repo-র ফাইলগুলো Kimi চ্যাটে আপলোড করুন (বা workspace-এ রাখুন)
2. প্রথম মেসেজে বলুন: "এই repo-র SKILL.md অনুসরণ করে বাংলাদেশের আইন বিষয়ে ডিজিটাল আইন সহকারী হিসেবে কাজ করো"
3. Kimi দীর্ঘ কনটেক্সট সাপোর্ট করে, তাই একাধিক ফাইল একসাথে দেওয়া যায়

## পদ্ধতি ২: Kimi Work skill হিসেবে

এই repo-র `SKILL.md` Kimi-এর skill ফরম্যাটের সঙ্গে সামঞ্জস্যপূর্ণ। Kimi Work-এ কাস্টম skill হিসেবে যোগ করলে প্রতিটি সেশনে স্বয়ংক্রিয়ভাবে লোড হবে — skill ডিরেক্টরিতে এই ফাইলটি রাখুন (যেমন `bangladesh-law-assistant/SKILL.md`)।

## পদ্ধতি ৩: Kimi প্লাগিন

পুরো repo-কে Kimi প্লাগিন হিসেবে প্যাকেজ করা যায় — এতে অন্য ব্যবহারকারীরাও এক ক্লিকে ইনস্টল করতে পারবে। বিস্তারিত Kimi-এর প্লাগিন ডকুমেন্টেশন দেখুন।

> টিপ: যেকোনো প্ল্যাটফর্মে সবচেয়ে গুরুত্বপূর্ণ ফাইলগুলো হলো `SKILL.md`, `guides/` ফোল্ডার, এবং `data/laws-index.json` — জায়গা কম থাকলে এগুলো আগে দিন।
