# Contributing

Contributions are very welcome! 🙏

## What you can contribute

- Add missing acts/ordinances with a short summary + official link
- Fix outdated information (laws change often — flag amendments!)
- Improve Bangla translations
- Add case law notes for important Supreme Court decisions
- Improve structure and documentation

## Rules

1. **Accuracy first** — every entry must link to its official source (preferably https://bdlaws.minlaw.gov.bd).
2. **No legal advice** — this repo is informational only. Never present content as legal advice.
3. **Neutral tone** — summarize laws factually; political commentary does not belong here.
4. **Date your updates** — laws change; note "as of YYYY" where relevant.
5. Use English for structure/headings; Bangla summaries alongside English are encouraged.

## How to contribute

1. Fork the repository
2. Create a branch: `git checkout -b add/labour-rules-2025`
3. Commit with a clear message: `Add Labour Rules amendment 2025 summary`
4. Open a Pull Request describing what you added and the official source
